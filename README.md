# 🔨 두더지 잡기

### 👉 [게임 하러 가기](https://nihao72-netizen.github.io/mole-game/)

https://nihao72-netizen.github.io/mole-game/

PC와 휴대폰 브라우저에서 바로 플레이할 수 있습니다.

## 플레이 방법

1. **게임 시작** 버튼을 누르면 30초 타이머가 시작됩니다.
2. 구멍에서 튀어나오는 것을 클릭(휴대폰은 탭)하세요.
   - 🐹 두더지 **+1점**
   - 🌟 황금 두더지 **+3점**
   - 💣 폭탄 **-2점** (피하세요!)
3. 시간이 지날수록 두더지가 더 빨리 숨습니다.
4. 최고 기록은 브라우저에 자동으로 저장됩니다.

## 만들면서 느낀 점

"두더지 게임을 만들어 줘"라고만 요청했는데, 황금 두더지·폭탄·최고 기록 저장처럼 제가 떠올린 것 이상의 요소가 들어가 있어서 감탄했습니다. 그러면서도 결과물을 직접 보니 부족한 부분이 눈에 들어왔습니다.

이번 경험으로, 처음부터 모든 것을 자세히 설명하기보다 먼저 대략적인 결과물을 AI에게 만들게 하고, 그걸 보면서 필요한 기능과 고칠 점을 정리해 다듬어 나가는 방식이 훨씬 빠르겠다는 생각이 들었습니다.
